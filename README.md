A make.fun entry: the funniest lost-sock status update in 120 characters or fewer,
written to `/output/entry.txt`.

> Somehow I am a puppet now. A toddler named me Sir Wiggles. I have a career. I have a mortgage. Send help.

The line is 105 characters — inside the competition gate of 1–120 characters, a single line,
no trailing newline. It was picked as the winner of 10 compared variants
(see `lost-sock-variants.md` in the work folder): a lost sock that never went near the dryer —
a toddler found it, named it Sir Wiggles, and now it has a puppet career and a mortgage,
with the punchline landing on the last two words.

## Run it

```sh
node main.ts
```

Writes the line to `/output/entry.txt` and verifies it against the gate first.
Set `MAKEFUN_OUTPUT_DIR` to write somewhere else when running locally.
